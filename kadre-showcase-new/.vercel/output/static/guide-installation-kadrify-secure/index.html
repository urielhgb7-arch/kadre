Créer votre base (Supabase)

Votre site utilise une base de données ultra-sécurisée. Créez un compte gratuit sur Supabase et récupérez ces 2 éléments :

Aller sur Supabase
  • 1
    Copier le Project URLDepuis l'accueil de votre projet Supabase, cliquez sur le bouton "Copy" en haut à gauche sous le nom du projet, et choisissez Project URL.
  • 2
    Copier la Clé AnonAllez dans les ⚙️ Project Settings (en bas à gauche) > API Keys. Cherchez la section Legacy anon, service_role API keys et copiez la clé avec le tag vert `anon` `public`.

02

L'Assistant Magique (CMS)

Ouvrez votre site dans le navigateur (en local ou une fois en ligne), et effectuez un triple clic rapide sur votre logo en haut à gauche.

Ce geste secret ouvre votre panneau de configuration CMS. Collez ici vos clés Supabase (copiées à l'étape 1), et vous pourrez modifier tous vos textes, images et couleurs en direct.

03

Le script SQL (Tables)

Toujours depuis votre Assistant Magique (CMS), vous trouverez une section contenant un script SQL à copier.

  1. Cliquez sur le bouton Copier le script SQL dans le CMS.
  2. Allez sur le site de Supabase, dans le menu SQL Editor (icône avec </>) à gauche.
  3. Cliquez sur New query.
  4. Collez le script et appuyez sur Run en bas à droite.

Succès ! Vos tables sont créées. Votre base est prête à recevoir les données.

SQL Editor
CREATE TABLE public.portfolio_data (
  id uuid NOT NULL,
  title text,
  created_at timestamp
);

-- Run successful!
