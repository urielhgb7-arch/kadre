Questions fréquentes

Comment personnaliser le contenu ?

Cliquez sur "Personnaliser" pour ouvrir le CMS intégré. Modifiez votre nom, titre, photo et compétences en direct. Aucun code requis.

Ai-je besoin d'un serveur payant ?

Non. Hébergez votre portfolio gratuitement sur Vercel, Netlify ou GitHub Pages. Le seul service payant (optionnel) est Supabase pour la persistance.

Puis-je utiliser plusieurs designs ?

Chaque design est vendu séparément avec une licence à vie. Achetez autant que vous souhaitez.

Le code source est-il inclus ?

Oui — HTML, CSS et JS complets. Le core CMS est protégé par obfuscation mais toujours fonctionnel.
